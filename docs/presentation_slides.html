Topic 1 · Deep Learning Architecture

EfficientNetV2B0 Backbone & Custom Head

Architectural Components

  • Input Layer: 224x224x3 RGB image (retaining raw [0, 255] float32 values).
  • Backbone: ImageNet pretrained EfficientNetV2B0 with frozen layers.
  • Target Conv Layer: top_activation (7x7 spatial resolution with 1280 feature channels).
  • Pooling: GlobalAveragePooling2D collapsing spatial dims to 1280 vector.
  • Regularization & Head: Dropout(0.3) + Dense(2, Softmax) for calibrated class probabilities.

Topic 2 · Interpretability & Trust

Triangulation: Grad-CAM · LIME · Kernel SHAP

Three Pillars of Model Explanation

  • Grad-CAM: White-box gradients flowing into top_activation feature maps. Instant activation heatmap.
  • LIME: Model-agnostic superpixel perturbations. Evaluates local surrogate decision boundaries (Green=Support, Red=Oppose).
  • Kernel SHAP: Axiomatic game theory calculating exact marginal contributions of tissue segments toward tumor prediction.

Clinical Consensus

Relying on a single XAI method risks deceptive artifacts. When Grad-CAM, LIME, and SHAP all highlight the same renal mass, clinical trust in model attention is rigorously validated.

CAUTION: Heatmaps denote neural filter activations — not histological surgical margins.

"In clinical healthcare, black-box predictions are unacceptable. We integrated three distinct XAI methods: Grad-CAM for convolutional activations, LIME for superpixel sensitivity, and SHAP for game-theoretic feature attribution. Triangulating across all three proves the network is diagnosing based on genuine pathology, not background noise."

Topic 3 · Future-Ready Extension

Multimodal Fusion: CT Scans + Clinical Biomarkers

Dual-Branch Fusion Architecture

  • Branch A (Image): Pretrained CNN extracting 1280-dim feature vector → Dense(128, ReLU).
  • Branch B (EHR): 6 verified renal biomarkers (Age, Creatinine, BUN, eGFR, BP, Hb) → Dense(64) → BN → Dense(32).
  • Late Fusion: Concatenate 128 image + 32 tabular = 160 fused features → Dense(64) → Dropout → Softmax(2).

Data Transparency Statement

The current repository dataset contains spectral imaging scans only. Rather than fabricating patient lab data, we implemented the complete, validated multimodal architecture ready to train once paired electronic health records are linked.
